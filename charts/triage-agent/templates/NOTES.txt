No triage core is set. To stream applications + Kubernetes Warning events to
the triage core, set:
  --set core.host=<triage-host> \
  --set core.clusterName=<name> \
  --set core.caFingerprint=<SHA256:... from GET /v2/agents on the core>

Or use the command the core prints when it mints an agent key (it adds
core.agentKey and needs no approval).

Without a key the agent joins by an admin-approved certificate: it logs
`join pending` with its key fingerprint; approve that fingerprint in the
core's sources panel or with POST /v2/agents/approve.
